## Start here

1. Extract the entire ZIP into a normal folder. Keep its structure together.
2. Open a terminal in the `website` folder.
3. With Node.js 22+ and Python 3 installed, run `npm run build`.
4. Run `npm run dev`, then open http://localhost:4325.
5. Stop the local server with Ctrl+C. If port 4325 is occupied, use
   `PORT=4326 npm run dev` on macOS/Linux, or `$env:PORT=4326; npm run dev`
   in PowerShell, and open that port instead.

No npm dependencies or API credentials are required. `npm run build` creates
the complete `dist` website, copies all media, and runs the existing checks.
The generated `dist` folder is intentionally not duplicated in the ZIP:
every asset is already present in `website/public`, and every page is rebuilt
from the editable source. Do not open raw HTML/template files directly.

This is a full source handover, not a WordPress export or a backend database
dump. The content and website data are local JSON, JavaScript modules and
generated CSV/JSON reports. There is no production enquiry database in this
review project. All website-ready images, logos, fonts, video files and
responsive variants are included; private chat/email archives and raw shoot
footage are not required to build the site and are not included.

The build applies several editorial/design layers. A change to an early source
can be overridden later. Check final-proof, editorial-review and customer-polish
when a change does not appear. Edit source, then rebuild; changes made only to
generated `dist` files are overwritten by the next build.

`page-copy` contains one readable Markdown copy for each of the 30 customer
pages. Its original 7.17 date is retained because the later releases changed
presentation, not customer copy. It is a writing reference, not the rendering
source. The root CSV/JSON files inside `website` describe current route, keyword,
metadata, section and content measurements and are regenerated by the build.
